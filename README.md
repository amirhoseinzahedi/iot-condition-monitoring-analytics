# IoT Condition Monitoring & Anomaly Detection

An end-to-end IoT data analytics project focused on environmental
condition monitoring, data quality analysis, time-series analysis,
and anomaly detection.

## Project Status

🚧 Work in progress

## Objectives

- Analyze multi-sensor IoT data
- Evaluate sensor data quality
- Identify temporal and spatial patterns
- Detect anomalous sensor behavior
- Build an analytics dashboard

## Sensors

- Temperature
- Humidity
- CO₂
- Air Speed
- Light

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter
- Power BI
- Git / GitHub
